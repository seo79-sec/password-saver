# Changelog

## [1.1.0] — подготовка к выпуску

### Добавлено

- Индивидуальное скрытие сохранённых паролей; ввод пароля в форме также скрыт по умолчанию.
- Настраиваемое время автоблокировки и очистки clipboard.
- Резервное копирование зашифрованного vault и подтверждаемое восстановление `.bak`.
- Автоматические проверки с race detector, проверки интерфейсных security helpers и сценарии восстановления.
- Документированный Windows release workflow, который собирает артефакт без публикации релиза.

### Улучшено

- Атомарная запись хранилища и согласованность изменений в памяти с результатом записи.
- Валидация зашифрованного контейнера и совместимость с ранее созданным `vault_data.enc`.
- Управление сессией, очистка чувствительного UI-состояния, ограничение попыток TOTP.
- Скрытое отображение паролей, безопаснее управляемая очистка clipboard и приватность favicon-запросов.
- HIBP сообщает о сетевой проверке и отправляет только первые пять символов локально вычисленного SHA-1.

### Ограничения

- Clipboard cleanup best effort; браузерный API не предоставляет атомарного compare-and-clear.
- Очистка интерфейса не гарантирует физическое стирание всех копий из памяти JavaScript.
- Выпуск не считается проверенным до завершения ручного тестирования на Windows и подтверждения зелёных GitHub Actions.
