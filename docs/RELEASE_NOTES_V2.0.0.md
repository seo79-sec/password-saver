# PasswordSaver Standard 2.0.0

Первый релиз PasswordSaver Standard с активным форматом **v2** для новых хранилищ.

## Основные возможности

- Новое пустое хранилище создаётся сразу в формате v2 с **AES-256-GCM** и **Argon2id** — без промежуточного файла v1.
- Обёртывание ключа данных по модели **DEK/KEK**, версионированный криптоконтейнер.
- Шифрованные резервные копии v2; восстановление после проверки мастер-пароля, подтверждения пользователя и сохранения повреждённого основного файла.
- Существующие хранилища v1 открываются через совместимый legacy-путь и могут быть явно мигрированы в v2.
- Необязательная TOTP-аутентификация, автоблокировка, скрытие паролей, безопасное копирование, поиск, генератор и категории.
- Windows 10/11 x64, Wails v2.12, Go 1.26.4, Svelte 3.

## Установка

Скачайте `PasswordSaver-Standard-2.0.0-Windows-x64.zip`, проверьте SHA-256 архива по `.zip.sha256`, распакуйте и запустите `password-saver.exe` из доступной для записи папки. Приложению требуется Microsoft Edge WebView2 Runtime.

Проверьте находящийся **внутри архива** `password-saver.exe.sha256` для контроля целостности исполняемого файла. Не переносите один `.exe` без файлов активного хранилища, если уже сохранили пароли.

## Важно

- Это редакция **Standard**, использующая AES-256-GCM. **Кузнечик-MGM и GOST Lab пока не входят в релиз.**
- **Не удаляйте** файлы `vault_data.v2.enc`, `vault_data.v2.enc.bak` и `vault_format.state`, если хотите сохранить хранилище.
- Для v1 предусмотрена отдельная явная миграция; автоматического отката v2 на v1 нет.
- Восстановление резервной копии может вернуть более раннее состояние, включая старые настройки TOTP.
- Серверная синхронизация, Self-Hosted VPS и облачные аккаунты **в 2.0.0 отсутствуют**.
- Приложение не проходило заявленного внешнего независимого криптографического аудита.
