# PasswordSaver Standard 2.5.0

PasswordSaver хранит пароли локально и шифрует хранилище с помощью
AES-256-GCM и Argon2id. Сборка предназначена для Windows x64 с Microsoft
Edge WebView2 Runtime.

## Что нового

- Обновлены окно входа, список паролей, раздел безопасности и управление
  хранилищем. Сохранены поиск, категории, настройка блокировки, TOTP и
  проверка паролей через HIBP по явному согласию.
- Данные отделены от EXE. В Windows активное хранилище находится в
  `%LOCALAPPDATA%\PasswordSaver\vaults\default`. Перенос существующих данных
  проходит после проверки и явного подтверждения с сохранением исходников.
- Для v2 можно сменить мастер-пароль с повторной аутентификацией, экспортировать
  зашифрованную копию, проверить её без записи и выбрать записи для импорта.
  Совпадения пропускаются по умолчанию. Можно создать отдельную запись.
- Заранее созданный ключ восстановления v2 позволяет установить новый
  мастер-пароль. Ключ показывается один раз. Его следует хранить вне
  компьютера, отдельно от зашифрованных копий. При включённом TOTP
  восстановление проверяет код выбранного снимка.

## Обновление и совместимость

Скачайте `PasswordSaver-Standard-2.5.0-Windows-x64.zip` и его `.zip.sha256`.
Сверьте архив, распакуйте его и проверьте EXE по `SHA256SUMS.txt`.
Перед пробным запуском старой версии или переносом сохраните зашифрованные
рабочие файлы, резервную копию и селектор. Исходные хранилища v1 и v2 читаются.
Контейнеру с включённым recovery key требуется обновлённый PasswordSaver.

Если пароль забыт и recovery key не был создан, восстановление доступа
невозможно. Отозванный ключ сохраняет доступ к прежним копиям с его обёрткой.
Ключ вместе с соответствующим файлом позволяет расшифровать его офлайн.
При восстановлении старого снимка будут возвращены его записи и настройки,
включая TOTP. [Подробности восстановления](V2_RECOVERY_KEY.md)
