# PasswordSaver 2.5. Выпущенные возможности и отложенные задачи

PasswordSaver Standard 2.5.0 опубликован с одним локальным хранилищем.
Поддерживаемый релизный формат — Windows x64. Для обычной работы с записями
учётная запись и сеть не требуются. [Релиз 2.5.0](https://github.com/seo79-sec/password-saver/releases/tag/v2.5.0)

| Этап | Состояние в 2.5.0 |
| --- | --- |
| 2.5-A. Локальное расположение | В Windows рабочие данные находятся в `%LOCALAPPDATA%\PasswordSaver\vaults\default\`. Подтверждённый перенос проверяет контейнеры, копирует файлы с побайтовой сверкой и сохраняет исходную папку. [Архитектура расположения](V2_5_STORAGE_ARCHITECTURE.md) · [План проверки переноса](WINDOWS_STORAGE_MIGRATION_TEST_PLAN.md) |
| 2.5-B. Несколько независимых хранилищ | Отложено по решению владельца. В проекте 3.0 сохраняется одно хранилище. |
| 2.5-C. Копии и импорт | Есть зашифрованный экспорт и полное подтверждённое восстановление, проверка целостности без записи и выборочный импорт. Совпадение можно пропустить или импортировать отдельной записью. [Внешние копии](V2_EXTERNAL_BACKUP.md) |
| 2.5-D. Локальное восстановление | v2 поддерживает смену мастер-пароля и заранее настроенный recovery key. Ключ открывает отдельную обёртку DEK и позволяет установить новый пароль с проверкой TOTP выбранного снимка. [Смена пароля](V2_MASTER_PASSWORD_CHANGE.md) · [Ключ восстановления](V2_RECOVERY_KEY.md) |
| Интеграция устройств и дополнительные возможности | Синхронизация, мобильный клиент, Windows Hello, разделение ключа по Шамиру и вложения отложены. Плашка о телефоне или QR описывает намерение, реализованного подключения в 2.5.0 нет. |

В Standard используются AES-256-GCM и Argon2id. Существующие файлы v1
поддерживаются для совместимости и явного перехода на v2. Прежние файлы,
теги и архивы выпуска сохраняются при последующих обновлениях.
[Издания](EDITIONS.md) · [Заметки выпуска 2.5.0](RELEASE_NOTES_V2.5.0.md)
