**PasswordSaver** — локальный настольный менеджер паролей на Go, Svelte и Wails. Хранилище использует AES-256-GCM и Argon2id. В версии 1.1 сохраняется совместимость с существующим форматом `vault_data.enc`.

## Возможности

- Локальное зашифрованное хранилище с зашифрованной резервной копией `.bak` и явным подтверждением восстановления.
- Необязательная двухфакторная аутентификация TOTP.
- Генератор паролей, категории, поиск и индикаторы состояния паролей.
- Сохранённые пароли скрыты по умолчанию; их можно копировать, не показывая.
- Настраиваемая автоблокировка через 1, 5, 10 или 15 минут и очистка clipboard через 15, 30 или 60 секунд.
- Необязательная проверка Have I Been Pwned (HIBP). Приложение вычисляет SHA-1 локально и отправляет HIBP только первые пять шестнадцатеричных символов хеша; открытый пароль не передаётся.
- Названия сервисов не отправляются стороннему favicon-сервису.

## Хранилище и приватность

Приложение читает и записывает `vault_data.enc` относительно текущего рабочего каталога. Запускайте его из доступного для записи каталога, который находится под вашим контролем. При последующих сохранениях предыдущий зашифрованный контейнер сохраняется как `vault_data.enc.bak`. Если основной файл отсутствует или повреждён, приложение проверяет резервную копию и запрашивает подтверждение восстановления; повреждённый файл сохраняется для диагностики.

Проверка HIBP выполняется только по явному действию пользователя и требует сети. Для тестирования используйте синтетические пароли. Открытые пароли HIBP не отправляются.

При блокировке интерфейс освобождает ссылки на чувствительные значения, но JavaScript и операционная система не гарантируют стирание каждой копии из памяти. Очистка clipboard выполняется best effort и зависит от доступа к системному буферу обмена.

## Требования для сборки

- Go **1.26.4 или новее**, согласно `go.mod`.
- Node.js **24** и npm (используйте npm из комплекта Node.js; CI устанавливает зависимости через `npm ci`).
- Wails CLI **v2.12.0**.
- Для сборки Windows-приложения из исходников: Windows 10/11, поддерживаемый Wails компилятор MinGW-w64 и инструменты WebView2. См. [инструкцию по установке Wails для Windows](https://wails.io/docs/gettingstarted/installation).
- Для запуска готового Windows-приложения требуется Microsoft Edge WebView2 Runtime.

## Сборка и тесты

```sh
go test ./...
go test -race ./...
go build ./...

cd frontend
npm ci
npm test
npm run build
cd ..

go install github.com/wailsapp/wails/v2/cmd/wails@v2.12.0
wails doctor
wails build -platform windows/amd64 -clean
```

Исполняемый файл появится в `build/bin/password-saver.exe`. Поддерживаемая релизная сборка — Windows x64. Подготовка кандидата для релиза и ручной план проверки Windows описаны в [инструкции выпуска](docs/RELEASING.md) и [плане ручного тестирования](docs/WINDOWS_MANUAL_TEST.md).

## Установка

Скачайте `password-saver.exe` со страницы GitHub Releases, проверьте опубликованную SHA-256 сумму и запускайте приложение из доступного для записи каталога. Требуется WebView2 Runtime. Перед перемещением или заменой файлов приложения сделайте копию `vault_data.enc` и `vault_data.enc.bak` вместе. Не используйте настоящее хранилище при ручных или разрушающих проверках.
